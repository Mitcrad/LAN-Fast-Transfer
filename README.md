局域网快传｜使用说明
====================

1. 先把压缩包完整解压，不能直接在压缩包内运行。
2. 双击“启动局域网快传.bat”。
3. 如果 Windows 防火墙弹出提示，只勾选并允许“专用网络”。
4. 电脑浏览器会自动打开网页。
5. 用手机扫描网页中的二维码或者手动输入ip进入同一个网页
6. 确保手机和电脑连接同一个 Wi-Fi
7. 手机和电脑输入相同的 4 位配对码，分别点击“连接并等待配对”。
8. 显示“已安全直连”后，即可互传文字、图片和文件。

停止服务
--------
直接关闭黑色启动窗口即可。

注意事项
--------
- 启动窗口必须保持开启。
- 此工具只适合可信的家庭或办公局域网；4 位码不是高强度密码。
- 文件通过 WebRTC 在两台设备之间直接传输，不会上传网络。
- 接收到的文件需要点击“保存文件”，由浏览器保存到下载目录。
- 超大文件会占用较多浏览器内存，实际可传大小取决于设备和浏览器。
- 若手机打不开地址，请确认两台设备在同一网络、允许了专用网络防火墙，并关闭路由器的“客户端隔离/AP 隔离”。
- 公司、校园和酒店 Wi-Fi 经常禁止设备互访，此时无法使用。
